# @turystack/entity

Type-safe domain entities with stable SuperJSON serialization identifiers.

## Installation

```bash
pnpm add @turystack/entity
```

### Peer dependencies

The host application provides these:

```bash
pnpm add superjson
```

## Documentation

Options, API reference and examples:

**https://tury.dev/libs/entity**

## Development

```bash
pnpm install
pnpm typecheck
pnpm check
pnpm test
pnpm build
```
